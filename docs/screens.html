D

Four rules, as UI decisions

Not principles on a slide. Each is a specific thing the interface must say or must never say, and each comes from a statute.

Rule 1 · IT Act s.1(4), First Schedule

Acknowledge, never promise

A dated promise to pay can be a promissory note, which the IT Act does not cover. An acknowledgment of the debt carries no date, so it stays an ordinary electronic record.

Yes"Yes, I owe ₹200"
No"I'll pay by Friday"
Rule 2 · Money-lending Acts

Never a rupee above the price

State money-lending laws define a loan by the interest it carries. So the price of the goods is the whole amount, always.

Yes"Pay ₹200 now"
No"₹200 + ₹10 late fee"
Rule 3 · Limitation Act s.18

Let debts die

Each written acknowledgment restarts the three-year limit. Ask again and again and a ₹200 debt never ends. So we ask once, and show old debts as expired.

Yes"Expired · no longer claimable"
No"Outstanding since 2023"
Rule 4 · BNS s.356 · CCPA 2023

Never shame, never charge

Public "defaulter" labels risk defamation, and repeated nudges for commercial gain are "nagging" under CCPA's dark-pattern guidelines.

Yes"Day 40 — ask, don't chase"
NoDefaulter lists · his name announced aloud · leaderboards
